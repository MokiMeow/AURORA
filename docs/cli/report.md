# Reporting CLI

Aurora-SE exposes governance reports aligned with the PDCA telemetry framework:

- aurora-se report weekly — generates docs/reports/weekly_governance.md summarizing metrics and dashboards.
- aurora-se report monthly — writes a monthly overview referencing incident logs.
- aurora-se report governance — produces a bundle summary for compliance sign-off.
- aurora-se report training — produces an adapter training status digest.

Artifacts are stored under docs/reports/ and referenced from governance bundles.
