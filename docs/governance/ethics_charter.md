# Aurora-SE Ethics Charter

AURORA-SE operates as an autonomous engineering system with the following ethical guardrails:

1. **Human Oversight** – All production changes require human approval or a documented emergency exemption.
2. **Data Privacy** – Planner and telemetry data are scoped to the originating workspace. Redaction policies are enforced prior to egress.
3. **Security First** – Secrets, credentials, and personal data are never logged. SBOM/CVE scans block releases with known critical issues.
4. **Transparency** – Autopilot sessions emit PDCA events, diff summaries, and reward rationales for audit trails.
5. **Fairness** – Reward adjustments and learning adapters are evaluated for bias before promotion.

This charter is reviewed quarterly by the governance committee and any deviations trigger an incident response review.
