# Reward & Evaluation Reporting

Reward explainability artifacts are stored under `artifacts/reward_reports/`. Each run produces `latest_reward.json` documenting component contributions and policy notes.

Evaluation artifacts are exported under `eval/results/`:
- `*_metrics.json` files for SWE-Bench runs (success rate, latency, exit codes)
- Compliance reports linking SBOM snapshots and telemetry excerpts
- Aggregated CSVs and dashboards generated by analytics scripts in this directory
