# Evaluation Datasets

This directory houses datasets used by the SWE-Bench harness.

- `swe-bench-lite/` – lite subset for nightly runs.
- `swe-bench-live/` – live benchmark data pulled weekly.
- `swe-bench-full/` – full benchmark with monthly cadence.

Use `scripts/fetch_swe_bench.sh` to synchronize datasets before running evaluations.
